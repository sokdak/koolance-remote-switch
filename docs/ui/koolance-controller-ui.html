화면 설계 원칙

  • 실제 LCD 해상도와 동일한 480×320 비율
  • 한 화면의 설정 항목은 최대 4개
  • 핵심 값은 24–64 px, 본문은 최소 14 px
  • 목표 온도와 펌프 단계는 한 값 전용 편집 화면
  • 편집값은 즉시 전송하지 않고 변경 목록에 보관
  • 장치 적용 후 KSM polling으로 실제 반영값 재검증

가상 조작

설정 화면에서 엔코더로 칠러, PC 기동, 알람·릴레이, 시스템 카테고리를 선택할 수 있습니다. 각 목록은 화면당 최대 4개 항목으로 페이지가 자동 전환되며, 엔코더 누름으로 값 편집 또는 실행 화면에 들어갑니다. BACK은 편집을 취소하거나 상위 화면으로 돌아갑니다.

오조작 방지

PC 운전 중 펌프 0단계는 별도 2초 확인을 요구하고, 모델 프로파일 변경은 PWR_LED가 OFF일 때만 허용합니다. 이슬점 이하 설정은 사용자의 결정에 따라 차단하지 않고 경고만 표시합니다.
